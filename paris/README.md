# bonjour.py 🥐

French flashcards for the terminal. A word appears, you guess, then the meaning and an example show up. A little French while you study.

Coded live in the Meowtropolis video **Paris, France — 2 hour study with me**.

```
bonjour! a little French while you study.

  card 1
  la pluie
  = the rain
  J'aime la pluie.
```

## Run it

Needs Python 3.8 or newer. No packages to install.

```
python bonjour.py         # 8 seconds per side
python bonjour.py 15      # slower, like in the video
```

Press `Ctrl+C` to stop. It tells you how many cards you saw.

## Ideas to extend it

- Add your own words to `CARDS` (any language works)
- Ask for the answer with `input()` and keep a score
- Show the cards you missed more often
