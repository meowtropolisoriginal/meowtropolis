# Meowtropolis 🐈

Code from the **Meowtropolis** YouTube channel: lofi Pomodoro sessions to study & code, one city at a time.

In every video Byte the cat naps by a window in a new city while we code a small Python project from scratch. Then the project runs for real: 4 × 25 min focus with 5 min breaks.

Every project is a single file that runs with plain Python 3.8+. Nothing to install.

| City | Project | What it does | Video |
| --- | --- | --- | --- |
| 🇵🇹 Lisbon | [`lisboa/tram28.py`](lisboa/) | Tram 28 rides from Martim Moniz to Prazeres while you focus | [watch](VIDEO_LISBOA) |
| 🇯🇵 Tokyo | [`tokyo/yamanote.py`](tokyo/) | A train loops the Yamanote Line, and every focus earns you a haiku | [watch](VIDEO_TOKYO) |

## Run one

```
cd tokyo
python yamanote.py
```

Each folder has its own README with options and ideas to extend the code.
